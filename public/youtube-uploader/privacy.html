Privacy Policy

SoSoValue / SoDEX YouTube Uploader · Last updated 4 September 2026

This policy covers the SoSoValue / SoDEX YouTube Uploader, a private internal tool that uploads videos from a Lark workspace to a YouTube channel its operators own. It is not a public service and is not offered to third parties.

This is not the SodexTracker privacy policy. SodexTracker is a separate product and is not covered by this document. This page is hosted here only because the same team operates both.

Who operates this tool

The tool is operated by Elias on behalf of SoSoValue. It runs on infrastructure controlled by the operator. There is no hosted service, no user accounts, and no sign-up.

Questions about this policy: eliasdegemu61@gmail.com

What the tool does

An authorised person posts a video in a private Lark group and supplies a title and description. The tool downloads that video, waits for the person to explicitly confirm, and uploads it to a YouTube channel the operator controls. Nothing is uploaded without that confirmation.

Google account data we access

The tool requests a single Google OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload — permission to upload videos to the authorising account's YouTube channel.

This scope allows the tool to create new videos. It does not allow the tool to read, edit or delete existing videos, read analytics, read comments, or access subscriber information, and the tool does not attempt to do any of those things.

During the one-time authorisation step, the tool may additionally request youtube.readonly for the sole purpose of displaying which channel was authorised, so the operator can confirm the correct channel was selected. No channel data is stored.

What we store, and for how long

  • A Google OAuth refresh token. Stored on the operator's own machine or server so the tool can upload without repeated sign-in. Never transmitted anywhere except to Google.
  • The video file. Downloaded temporarily, uploaded to YouTube, then deleted. Videos that are cancelled or abandoned are deleted automatically.
  • Video metadata. The title, description and tags supplied by the authorised person, kept in a local database as a record of what was published.
  • Lark identifiers. The group and user identifiers of authorised people, used only to verify that a request came from someone permitted to publish.
  • Operational logs. Timestamps and status of uploads. Credentials and tokens are automatically redacted from all log output.

What we do not do

  • We do not sell, rent or trade any data.
  • We do not share Google user data with third parties.
  • We do not use Google user data for advertising, profiling, or training machine learning or AI models.
  • We do not allow humans to read Google user data, except as strictly necessary to fix a fault, with the user's consent, or where required by law.
  • We do not collect data from anyone other than the authorising account holder.

Limited Use disclosure

The SoSoValue / SoDEX YouTube Uploader's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. By authorising it you are also agreeing to the YouTube Terms of Service, and Google's Privacy Policy applies to Google's own handling of your data.

Revoking access

You can revoke this tool's access to your Google account at any time at myaccount.google.com/permissions. Doing so immediately and permanently prevents further uploads.

To have stored data deleted, email the address above. Deleting the stored token file removes all Google credentials; local video files and metadata can be deleted on request.

Security

Credentials are stored in files readable only by the account running the tool, and are excluded from version control. The tool holds the narrowest permission that lets it do its job, so a compromised credential cannot alter or remove existing content on the channel.

Children

This tool is an internal operational utility and is not directed at or usable by children.

Changes

If this policy changes, the revision date above will be updated.
